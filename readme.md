**Dark Caves RPG**
Jednoduchá, ale komplexní textová RPG hra napsaná v C#. Hráč si vybere svou třídu, bojuje s monstry v různých lokacích, sbírá vybavení a vylepšuje svou postavu.

Funkce hry:
- Tři hratelné classy
- Tahový soubojový systém
- Systém vybavení
- Lokace a progrese
- Získávání XP, lvling up a správa peněz
- Ukládání dat hráče do formátu JSON

Technické detaily:
- Jazyk C# NET 6.0 +
- Serializace System.Text.Json pro ukládání a načítání pozic.
- Struktura: Objektově orientované programování (třídy pro hráče, engine, menu a statistiky předmětů).

Instalace a spuštění:
- Ujistit se že máte nainstalované .NET SDK.
- zkopírujte kod do souboru Program.cs
- V terminálu zadejte příkaz "dotnet run"

Plánované Vylepšení:
- Přidání obchodu aby peníze měli využití
- Více typů nepřátel a lokací
- Skill tree
